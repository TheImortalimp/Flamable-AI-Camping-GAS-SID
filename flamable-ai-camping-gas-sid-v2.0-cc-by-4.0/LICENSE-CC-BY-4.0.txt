==============================================================================
  FILES INCLUDED IN THIS PACKAGE (UPLOAD TO imortalimp.nl ROOT)
==============================================================================
  1. flamable-ai-camping-gas-sid.html
     Main v2.3 web application. Contains external references to the .js and
     .json files plus embedded inline fallbacks so it runs both online on
     https://imortalimp.nl/flamable-ai-camping-gas-sid.html and offline.

  2. flamable-ai-camping-gas-sid.js
     Standalone v2.3 Web Audio MOS 6581/8580 wavetable synth engine (Square PWM,
     Triangle, Sine, LFSR SID Noise), Quick Tunes + Wavetable Instrument
     Confluence engine, 4-Row Live Play-In & Overdub Recorder, Violet-Armed
     Active-Voice Synth Lock, 4-Voice 32-Step Tracker, Programmable Song
     Arranger, One-Click 2–6 Minute Varied Song Generator, Multi-Slot Browser
     Save States Manager, and Direct-DSP .WAV, .MID, and .JSON exporters.

  3. flamable-ai-camping-gas-sid.json
     Companion JSON bank containing 12 Square/Triangle/Sine wavetable synth
     patches, musical scales, 50 Hz C64 arpeggio tables, signature presets,
     and CC BY 4.0 attribution metadata.

  4. flamable-ai-camping-gas-sid-source.html
     Visitable HTML Source Code Browser displaying all project files (.js,
     .json, .html, README.md, DESCRIPTION.md, LICENSE-CC-BY-4.0.txt) with
     one-click copy and download.

  5. README.md & DESCRIPTION.md
     Complete v2.3 usage guide and technical architecture documentation.

  6. LICENSE-CC-BY-4.0.txt
     This Creative Commons Attribution 4.0 International license & attribution
     notice crediting River Lyle Reuveni (imortalimp.nl) & Arena.ai Agent.

  7. imortalimp-root/index.html, home.html & i-know-better.html
     Updated imortalimp.nl homepage with the 90% x 90% top SID v2.3 showcase
     and the big "I KNOW BETTER" link button (just before <--Zuider Zee Brug-->)
     opening /i-know-better.html (popout video player for
     /foobar2000_zu7N7Bp2vz.mp4).
